# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository ini

git clone https://github.com/ramdiniokt-stack/library-system.git

2. Masuk ke folder project

cd library-system

3. Install dependency

composer install

4. Copy file environment

cp .env.example .env

5. Generate application key

php artisan key:generate

6. Sesuaikan konfigurasi database di file `.env`
7. Buat database baru bernama `library-system`
8. Jalankan migration

php artisan migrate

9. Jalankan aplikasi

php artisan serve

10. Buka browser ke `http://127.0.0.1:8000/`
